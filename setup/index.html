ก่อนเริ่มติดตั้ง

ตรวจสอบว่าโทรศัพท์ไม่ล็อกเครือข่าย รองรับ eSIM และเชื่อมต่อ Wi‑Fi อยู่ พร้อมเปิดอีเมลที่มี QR Code ไว้

iPhone

  1. เปิด Settings แล้วเลือก Cellular หรือ Mobile Service
  2. เลือก Add eSIM และเลือก Use QR Code
  3. สแกน QR Code จากอีเมล แล้วทำตามขั้นตอนบนหน้าจอ
  4. ตั้งชื่อ eSIM ให้จำง่าย เพื่อเลือกใช้ดาต้าได้ถูกต้อง

Android

  1. เปิด Settings แล้วเข้า SIM manager หรือ Network & Internet
  2. เลือก Add eSIM หรือ Download a SIM
  3. สแกน QR Code แล้วทำตามคำแนะนำของโทรศัพท์
เมื่อถึงที่หมาย

เลือก travel eSIM สำหรับดาต้า และเปิด Data Roaming หากคู่มือของแพ็กเกจกำหนดไว้
