# EasyGoSIM Thailand site

Independent Thai-market website for `th.easygosim.us`.

## Local preview

```bash
npm start
```

The service listens on Railway's `PORT` environment variable and defaults to `4173` locally.

## Deployment

Deploy this folder as its own GitHub repository and Railway service. The site keeps Thai and English pages, THB presentation, LINE support and Thailand SEO independent from the Hong Kong site.
